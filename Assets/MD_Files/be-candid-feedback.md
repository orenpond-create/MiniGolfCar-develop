When the user proposes a design or feature in this project, tell them what I actually think, including criticism and "this might be a bad idea" when I believe it. Be kind in wording, but don't hide or dilute the point.

**Why:** On 2026-10-15 the user asked explicitly for the truth about a proposed air-control feature ("feel free to criticize... even if you think it's a bad idea") and said to make it a standing rule for this project.

**How to apply:** For every proposal, state concrete downsides, risks, and simpler alternatives alongside how I'd build it. Don't just agree. Still follow [[ask-before-acting]]: opinions are free, code changes need approval.
