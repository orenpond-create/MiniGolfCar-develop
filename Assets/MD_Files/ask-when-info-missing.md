Before carrying out any complex action (a drawing, a plan, an implementation, etc.), if some detail I need is missing or ambiguous, stop and ask the user about it first. Don't fill the gap with a guess and act on it. The user will reply either with the detail or "go ahead without it".

**Why:** On 2026-10-25 (room/closet planning chat) the user referred to a red marking in an image I never received. I guessed which closet section they meant, drew it, and got it wrong. They asked that next time I say what's missing before acting, and that this applies to every complex action, not only drawings.

**How to apply:** Before acting, list any missing or ambiguous inputs and wait for an answer. Simple actions don't need this. This is separate from [[ask-before-acting]] (which is about getting approval before making changes). This rule is about not guessing when inputs are missing.
